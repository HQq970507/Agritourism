# 病虫害防治

## 真菌性病害

### 白粉病
- **危害对象**: 黄瓜、草莓、葡萄、月季、苹果等
- **症状识别**: 叶片正面出现白色粉状霉层，严重时叶片卷曲、枯黄；幼果表面也出现白粉
- **发病条件**: 温度20-25°C、湿度较大时高发；通风不良、光照不足易发病
- **化学防治**: 三唑酮（粉锈宁）1500倍液、醚菌酯悬浮剂、硫磺悬浮剂
- **生物防治**: 枯草芽孢杆菌、哈茨木霉菌喷洒；牛奶稀释10倍喷洒也有一定效果
- **有机防治**: 小苏打500倍液喷洒（1茶匙小苏打+1升水）；硫磺粉熏蒸
- **预防措施**: 保持通风透光；避免过量施氮肥；及时清除病叶

### 霜霉病
- **危害对象**: 葡萄、黄瓜、白菜、莴笋、洋葱等
- **症状识别**: 叶片正面出现黄色不规则病斑，背面产生灰白色或紫色霉层；病斑逐渐干枯
- **发病条件**: 温度18-24°C、高湿度（90%以上）时极易发病；雨水多、雾天高发
- **化学防治**: 烯酰吗啉、甲霜灵锰锌、霜脲氰悬浮剂
- **生物防治**: 木霉菌制剂、枯草芽孢杆菌
- **有机防治**: 波尔多液（硫酸铜:石灰:水=1:1:200）喷洒；大蒜浸出液喷洒
- **预防措施**: 选择抗病品种；避免密植；雨后及时排水；实行轮作

### 根腐病
- **危害对象**: 番茄、辣椒、茄子、黄瓜、果树苗木等
- **症状识别**: 植株根部变褐腐烂，地上部叶片萎蔫、黄化；严重时整株枯死；拔出可见根系变黑
- **发病条件**: 土壤积水、透气性差；连作地发病率高；土壤带菌
- **化学防治**: 多菌灵500倍液灌根、噁霉灵、甲霜灵灌根
- **生物防治**: 哈茨木霉菌、枯草芽孢杆菌灌根
- **有机防治**: 生石灰撒施消毒土壤；草木灰撒施根周
- **预防措施**: 实行3年以上轮作；选用抗病砧木；土壤改良增加有机质；避免积水

### 炭疽病
- **危害对象**: 草莓、葡萄、柑橘、辣椒、西瓜等
- **症状识别**: 叶片出现圆形褐色病斑，边缘明显；果实表面凹陷褐色斑块；高温多雨时严重
- **发病条件**: 温度25-30°C、高湿度；雨水传播孢子；果实近成熟期易感病
- **化学防治**: 咪鲜胺、苯醚甲环唑、嘧菌酯
- **生物防治**: 枯草芽孢杆菌、多粘类芽孢杆菌
- **有机防治**: 石硫合剂喷洒；波尔多液预防
- **预防措施**: 清除病残体；避免果实接触地面；合理修剪保持通风

### 灰霉病
- **危害对象**: 草莓、番茄、葡萄、黄瓜、花卉等
- **症状识别**: 花朵和果实表面出现灰色霉层；花瓣和叶片呈水渍状腐烂；有特殊霉味
- **发病条件**: 温度15-25°C、高湿度；开花坐果期易感病；棚室种植高发
- **化学防治**: 腐霉利、嘧霉胺、异菌脲
- **生物防治**: 木霉菌制剂、枯草芽孢杆菌
- **有机防治**: 加强通风降湿；及时摘除病花病果
- **预防措施**: 降低棚室湿度；避免叶面喷水；增加磷钾肥

## 细菌性病害

### 青枯病
- **危害对象**: 番茄、辣椒、茄子、马铃薯等茄科作物
- **症状识别**: 植株突然萎蔫，但叶片仍保持绿色；茎部横切可见维管束变褐色；挤压有菌脓溢出
- **发病条件**: 高温高湿（30°C以上）；酸性土壤；连作地发病重
- **化学防治**: 农用链霉素、噻菌铜、氢氧化铜
- **生物防治**: 荧光假单胞杆菌、芽孢杆菌制剂
- **有机防治**: 石灰调酸土壤；草木灰撒施
- **预防措施**: 嫁接育苗（用抗病砧木）；与水稻轮作；酸性土壤施石灰

### 软腐病
- **危害对象**: 白菜、萝卜、芹菜、马铃薯等
- **症状识别**: 组织软化腐烂，有恶臭；叶柄或根部呈水渍状软腐；干燥后组织皱缩
- **发病条件**: 温度25-30°C、高湿度；虫害伤口多时易发；储存期也易发病
- **化学防治**: 噻菌铜、氢氧化铜、农用链霉素
- **生物防治**: 枯草芽孢杆菌
- **预防措施**: 防治地下害虫减少伤口；避免大水漫灌；收获后及时晾晒

## 虫害

### 蚜虫
- **危害对象**: 几乎所有蔬菜和果树
- **症状识别**: 聚集在嫩叶、嫩芽和花蕾上吸食汁液；叶片卷曲变形；分泌蜜露引发煤污病
- **发生规律**: 春季和秋季为两个发生高峰期；繁殖力极强，一年可繁殖10-30代
- **化学防治**: 吡虫啉、啶虫脒、高效氯氟氰菊酯
- **生物防治**: 瓢虫（天敌）、草蛉、食蚜蝇；蚜茧蜂寄生
- **有机防治**: 肥皂水喷洒（1:50）；辣椒水浸出液；苦参碱制剂
- **预防措施**: 黄板诱杀；覆盖防虫网；间作薄荷、大蒜等驱避植物

### 红蜘蛛
- **危害对象**: 草莓、茄子、辣椒、果树、花卉等
- **症状识别**: 叶片正面出现细小黄色斑点；严重时叶片变黄脱落；叶背可见细小红色蜘蛛
- **发生规律**: 干旱炎热天气高发（6月-8月）；繁殖速度快，5-7天一代
- **化学防治**: 阿维菌素、哒螨灵、炔螨特
- **生物防治**: 捕食螨（胡瓜钝绥螨、智利小植绥螨）
- **有机防治**: 矿物油乳剂喷洒；大蒜水浸出液；勤喷水增加湿度抑制繁殖
- **预防措施**: 保持田间湿度；及时清除杂草；释放捕食螨

### 菜青虫（菜粉蝶幼虫）
- **危害对象**: 白菜、萝卜、甘蓝等十字花科蔬菜
- **症状识别**: 啃食叶片形成孔洞和缺刻；严重时仅剩叶脉；粪便污染菜心
- **发生规律**: 春季4月-6月和秋季9月-10月两个高峰期
- **化学防治**: 高效氯氰菊酯、甲维盐、苏云金杆菌（Bt）
- **生物防治**: 赤眼蜂寄生卵；苏云金杆菌（Bt）制剂
- **有机防治**: 覆盖防虫网；人工捕捉；苦参碱制剂
- **预防措施**: 覆盖防虫网；间作驱避植物（薄荷、茴香）；及时清除老叶

### 潜叶蝇
- **危害对象**: 豆类、瓜类、蔬菜、花卉等
- **症状识别**: 叶片表面有白色弯曲的虫道（潜道）；严重时叶片枯白
- **发生规律**: 春秋季高发；温暖地区全年发生
- **化学防治**: 阿维菌素、灭蝇胺、溴氰虫酰胺
- **生物防治**: 潜叶蜂（寄生性天敌）；黄色粘虫板
- **有机防治**: 黄板诱杀成虫；及时清除受害叶片
- **预防措施**: 覆盖防虫网；避免连作；清理田间杂草

### 蜗牛和蛞蝓
- **危害对象**: 草莓、生菜、白菜、花卉幼苗等
- **症状识别**: 叶片被啃食成不规则孔洞；可见黏液痕迹；幼苗整株被咬断
- **发生规律**: 潮湿阴凉天气高发；夜间活动取食
- **化学防治**: 四聚乙醛（蜗牛敌）颗粒撒施
- **有机防治**: 撒施草木灰或石灰粉于植株周围；啤酒诱捕；人工捕捉
- **预防措施**: 清除杂草和落叶；保持田间干燥；地面覆盖地膜

## 综合防治原则

### IPM（有害生物综合治理）
1. **农业防治** - 合理轮作、选用抗病品种、加强肥水管理、清洁田园
2. **物理防治** - 黄板蓝板诱杀、杀虫灯、防虫网、银灰膜驱避
3. **生物防治** - 天敌昆虫保护与释放、微生物制剂使用、植物源农药
4. **化学防治** - 科学用药、对症下药、轮换用药、遵守安全间隔期

### 农药使用安全原则
- 严格遵守安全间隔期（最后一次施药到收获的天数）
- 交替使用不同作用机制的农药，避免抗药性
- 选择高效低毒低残留农药
- 保护授粉昆虫（蜜蜂等），花期慎用农药
- 按照推荐剂量使用，不可随意加量
